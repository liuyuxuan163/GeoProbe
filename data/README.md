# 数据说明

## 文件

| 文件 | 组 | 内容 | 是否带坐标 |
|---|---|---|---|
| `words_control.json` | A · control | 无歧义地名（城市 + 国家），**探针训练集** | ✅ |
| `words_ambiguous.json` | B · ambiguous | 歧义地名，**用 A 组的探针测试** | ✅（+ 可选备选坐标） |
| `words_nongeo.json` | C · nongeo | 非地名常用词，**负对照** | ❌（无真实坐标） |

## 字段

```json
{
  "word": "Georgia",                      // 必填，模型输入用
  "lat": 42.3154, "lon": 43.3569,         // 主含义坐标（B 组是"地理含义"）
  "label": "格鲁吉亚（国家）",              // 人类可读说明
  "alt_lat": 32.1656,                     // 可选：备选含义坐标
  "alt_lon": -82.9001,
  "alt_label": "美国佐治亚州",
  "note": "为什么选它"                      // 可选：分析时参考
}
```

**`alt_lat/alt_lon` 是本项目的关键设计**：有了备选坐标，就能回答
"模型把这个词的预测拉向了哪个含义"，而不只是"误差多大"。

## ⚠️ 坐标精度说明

**内置坐标是城市中心 / 国家地理中心的近似值，精度约 ±0.5 度（≈ 50 km）。**

对于 0.5B 级别的小模型来说，这个精度**远小于**模型本身的误差量级
（预期中位误差在数百到数千公里），所以不影响结论。

但如果你要发表或对外展示结果，应该用权威数据源刷新：

```bash
# 需要 geopy
pip install geopy
python scripts/build_wordlist.py --refresh
```

`build_wordlist.py` 会用 OpenStreetMap Nominatim 查询经纬度，
并**保留人工核对过的 `note` / `label` 字段**。

## 为什么 B 组的"真值"取地理含义

`Georgia` 的真值取**国家格鲁吉亚**（42.3154, 43.3569），
而不是美国佐治亚州。原因是：

- 探针在 A 组（纯地名）上训练，学的是"**地名 → 坐标**"的映射
- 测 B 组时，如果预测落在美国，说明**模型对这个词的表征被更常见的非地理/他国含义主导**
- 备选坐标（`alt_*`）用于量化"偏向程度"

这正是本项目要回答的问题。
