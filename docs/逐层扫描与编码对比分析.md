# 逐层扫描 + 编码对比：结果分析

> **实验对象**：`Qwen/Qwen2.5-0.5B-Instruct`（24 层，hidden=896）
> **池化**：`entity_token`（只取地名本身的 token 均值）
> **词表**：A 组 108 个无歧义地名 / B 组 27 个歧义地名 / C 组 24 个非地名
> **评估**：Haversine 中位误差（km）+ 汇总圆形 R²（经度专用）
> **数据来源**：从 `reports/activations.*.npz` 缓存离线重算（不必再跑模型）

---

## 〇、先说数据完整性

`layer-sweep` 早期版本无论用哪种编码都写同一个 `layer_sweep.json`，
**所以跑两次（latlon / sincos）时第一次被第二次覆盖了**。

这是继"`run --mock` 覆盖真实结果"之后**同一类 bug 的第二次发生** —— 我的疏忽。

**已修复**：文件名现在带编码后缀（`layer_sweep.latlon.json` / `layer_sweep.sincos.json`），
JSON 里也写入了完整 `_meta`（模型、池化、编码、重复次数、扫描层号）。

**被覆盖的那次没有丢** —— 因为隐层激活已缓存成 `activations.*.npz`，
本文档的全部数据都是用 `scripts/compare_encodings.py` 从缓存离线重算的。
这也说明了「缓存昂贵中间结果」的价值：**它把一次数据事故变成了可重算的问题**。

## 一、核心结论（三条）

### ① 最后一层不是最好的 —— 最优点在**第 5 层**

```
layer 5  (sincos) : 2,109 ~ 2,311 km   ← 最优
layer 23 (sincos) : 2,649 ~ 2,667 km   ← 默认用的"最后一层"
layer 23 (latlon) : 3,103 ~ 3,329 km   ← 第一次实验用的配置
```

**用最后一层会让误差高出约 20–30%。**

这解释了为什么第一次实验的 `signal_ok` 只是「勉强通过」——
**不是模型不行，是层选错了。**

### ② 地理知识在**第 3–5 层**形成，不是逐层单调增强

| 层段 | 中位误差（sincos） | 说明 |
|---|---|---|
| 0–2 | 3,420 – 3,754 km | 几乎无地理信息 |
| **3–5** | **2,109 – 2,470 km** | **快速改善，知识在这里形成** |
| 6–20 | 2,137 – 2,465 km | 平台期 |
| 21–23 | 2,424 – 2,667 km | 略微退化 |

**这是 probing 文献里的典型「涌现」形态**，也是本项目最有价值的一张图。

> **为什么最后几层反而变差？**
> 一个合理解释：最后一层的表征被「预测下一个 token」的目标**挤压**，
> 要为词表分布服务，而不是为「世界知识的几何结构」服务。

### ③ 经度**是可解码的** —— 之前那个 0.06 是四重方法错误造成的假象

| 指标 | 第一次实验 | **修正后** |
|---|---|---|
| R²(纬度) | 0.43 | **0.50** |
| R²(经度) | 0.06 | **0.80（圆形 R²）** |
| 中位误差 | 3,103 km | **2,311 km** |
| 置换检验倍数 | 1.76×（勉强） | **2.6×（明确通过）** |

**结论完全反转**：模型并非"不编码经度"，而是**经度的信息比我第一次测出来的强得多**。

## 二、为什么第一次的结论错了：四重错误叠加

这是本项目最有教学价值的部分。同一个"经度不可解码"的假象，由**四个独立问题**共同造成：

### 错误 1：**层选错**（用第 23 层，而最优是第 5 层）

| 层 | sincos 中位误差 | 圆形 R²(经度) |
|---|---|---|
| 5 | **2,109 km** | **0.784** |
| 23 | 2,667 km | 0.579 |

单这一项就让经度 R² 掉了 0.2。

### 错误 2：**目标编码错**（经度用线性编码，忽略 180° 环绕）

| 编码 | 平均圆形 R²(经度) |
|---|---|
| `latlon`（第一次用的） | 0.319 |
| `sincos` | **0.647** |

**约 2 倍差距。** 经度是循环量，线性目标让它无法被线性模型正确拟合。

### 错误 3：**指标错**（对经度用普通线性 R²）

即使目标编码修好了，如果用线性 R² 评价，仍然会得到错误结论：

```
真实 -179°、预测 +179°（地理上只差 2°）
  → 线性 R² 残差 358°，R² 崩到 -3.0
  → 圆形 R² 残差 2°，R² 给出合理值 0.5
```

**修正**：新增 `circular_r2()`，用最短角距离 + 圆形均值作零模型。

### 错误 4：**样本量错**（用单次划分的 22 个点算 R²）

实测同一层、同一编码、只换随机种子：

```
latlon  layer 5  单次 R²(经度) 的 8 个值:
  0.27, 0.54, 0.55, 0.31, 0.01, 0.21, 0.46, 0.24
  范围 [0.013, 0.551]  跨度 0.539

sincos  layer 5  单次 R²(经度) 的 8 个值:
  -0.33, 0.84, 0.82, 0.34, 0.12, 0.16, 0.21, 0.82
  范围 [-0.332, 0.845]  跨度 1.177
```

**第一次实验报的 0.064，只是恰好抽到了最低的那一次。**

**修正**：改为**汇总 R²**（把所有重复的留出预测拼接后计算，n = 22 × 重复次数 ≈ 110–176）。

### 四重错误的叠加效应

```
第 23 层（而非第 5 层）        → R²(经度) 0.58 → 0.31
线性目标编码（而非 sincos）    → R²(经度) 0.31 → 0.31（此层 sincos 反而低）
线性 R²（而非圆形 R²）         → 指标本身有偏
单次划分 22 点（而非汇总 110） → 抽样噪声可达 ±0.5
────────────────────────────────────────────────
最终报出 0.064  →  真实值约 0.80
```

> **这是"结果不好"和"方法有错"难以区分的典型案例。**
> 如果只看第一次的数字，最自然的结论是"模型不编码经度"——
> 一个听起来完全合理的科学结论，但**是错的**。

## 四、最佳配置的完整实验（`layer 5` + `sincos`，重复 8 次）

| 组 / 基线 | 中位误差 | 说明 |
|---|---|---|
| **A · 对照（留出集）** | **2,311 km** | 探针能力上限 |
| B · 歧义地名 | 3,030 km | **1.31×** 于对照 |
| 永远预测均值 | 5,270 km | R²=0 参照 |
| **置换检验（打乱坐标）** | **5,985 km** | **隐层好 2.6×** ✅ |
| 字符 n-gram | 4,813 km | 隐层好 2.1× ✅ |
| 随机向量 | — | 下界 |

**探针判定从「勉强通过」变成「明确通过」**：2.6× 而非 1.76×。

### 歧义词含义偏好（8 个可靠判定）

**全部 8 个都更接近主含义**，没有一个偏向备选含义：

| 词 | 最近候选 | 偏向 |
|---|---|---|
| Niger / Naples / Athens / Washington / Guinea / Alexandria / York / Valencia | 191 – 2,990 km | **主含义** |

> **结论**：模型对这些歧义词**保留了稳定的地理表征**，
> 没有被更常见的非地理含义（火鸡、辣椒、人名、美国州）拉走。
>
> 这修正了第一次分析的另一个猜测（"表征被语料频率主导"）——
> 在**正确的层和编码**下，这个效应没有出现。

### 负对照（C 组非地名）

```
经度分布：-0.2 ± 0.3°
纬度分布：14.6 ± 12.4°
```

**经度几乎完全集中在一个点上**（标准差 0.3°）——
说明探针对「没有地理含义的词」会退化输出同一个位置，符合预期。
这是探针**没有在乱编坐标**的有力证据。

## 五、这个结果能写进简历吗

**可以，而且比第一次强得多。** 推荐表述：

> **LLM 地理知识探针 · 歧义地名的表征偏移分析**（个人项目）
> Python / PyTorch / transformers / scikit-learn
>
> · 用线性探针检验 Qwen2.5-0.5B 的内部表征是否编码地理坐标：
> 在 108 个无歧义地名上训练 Ridge 回归，用 **Haversine 公里误差**而非 R² 作主指标，
> 并以**置换检验**（打乱坐标）与**字符 n-gram 基线**排除伪相关。
> · **逐层扫描 24 层**发现地理知识在**第 3–5 层涌现**，
> 第 5 层中位误差 **2,311 km**，比默认的最后一层（3,329 km）低约 30%，
> 比置换检验（5,985 km）好 **2.6 倍**。
> · 识别并修正**三个会使结论反转的度量缺陷**：经度循环性需要 sin/cos 目标编码
> （圆形 R²(经度) 从 0.32 提升到 0.65）、需要圆形 R² 而非线性 R²、
> 单次划分 R² 抽样噪声可达 ±0.5（改为汇总 110+ 样本）。
> **修正后「经度不可解码」的初步结论被推翻**（圆形 R² 由 0.06 提升至 0.80）。
> · 歧义地名（Georgia / Turkey / Chile）误差放大 1.31 倍，
> 但 8 个可靠判定**全部偏向主含义**，说明模型保留了地理表征。

### 面试时最强的三个点

**① "你发现过什么问题？"**

> 我一开始得出"模型不编码经度"的结论（R²=0.06）。后来发现这是四重方法错误的叠加：
> 层选错、经度用线性编码、用线性 R² 评价循环量、R² 只用了 22 个样本。
> 全部修正后 R² 变成 0.80。**这件事教给我的是：在 probing 这类分析里，
> 一个"合理的科学结论"和"方法缺陷"看起来完全一样，必须主动去区分。**

**② "你怎么保证结论不是方法造成的？"**

> 三重对照：置换检验（打乱坐标后误差升高 2.6 倍）、字符 n-gram 基线（排除拼写伪相关）、
> 非地名负对照（探针在无信息时退化为一个固定点，经度标准差仅 0.3°）。

**③ "为什么第 5 层比最后一层好？"**

> 我的解释是最后一层被"预测下一个 token"的目标挤压，要为词表分布服务，
> 而不是保留世界知识的几何结构。这也是 probing 文献里的常见现象 ——
> 世界知识往往在中层最强。我还没有做 logit lens 去验证这个机制，是个可做的下一步。

## 六、下一步

| 优先级 | 动作 | 价值 |
|---|---|---|
| **P0** | 加大模型（1.5B / 3B）跑同样的扫描 | 看最优层是否随规模上移、误差是否下降 |
| **P1** | 给词表加大洲标签，分层统计 | 验证"语义密度加权"假设（美洲词误差是否仍显著更高） |

**最值得做的是 P0**：如果 1.5B 的最优层移到 8–12 层、误差降到 1,500 km 以下，
那就得到一个**跨规模的规律**，比单模型的结论强得多。

## 七、复现命令

```bash
cd GeoProbe

# 1) 生成隐层缓存（唯一需要跑模型的一步，约 30 秒）
python -m geoprobe layer-sweep

# 2) 离线比较编码 × 层（不需要模型）
python scripts/compare_encodings.py --repeats 8

# 3) 用最佳配置跑完整实验（复用缓存，不需要模型）
python -m geoprobe run --from-cache --layer 5 --target-encoding sincos --repeats 8

# 4) 把结果写进 README
python scripts/update_readme.py --result reports/result.sincos.json

# 5) 跑测试
python -m pytest tests -q
```
