## 一、一句话结论

> **探针有效但信号很弱；最重要的发现是「纬度可解码、经度几乎不可解码」；
> 歧义效应的证据不足，且其中「偏向备选含义」的判定大部分是噪声。**

## 二、核心数字

| 指标 | 值 | 解读 |
|---|---|---|
| 对照中位误差（5 次平均） | **3,103 km**（±685） | 约等于伦敦到莫斯科的距离 |
| 对照中位误差（单次） | 2,539 km | 单次波动大，所以要看 5 次平均 |
| 歧义组中位误差 | 3,869 km（±691） | 比对照差 1.25 倍 |
| **置换检验基线** | **5,455 km** | 打乱坐标后 —— 隐层比它好 **1.76 倍** |
| 字符 n-gram 基线 | 5,268 km | 隐层比它好 1.70 倍 |
| 均值基线 | 5,282 km | 隐层比它好 1.70 倍 |
| 随机向量基线 | 5,172 km | 隐层比它好 1.67 倍 |
| **R²（纬度）** | **0.427** | 有相当的解释力 |
| **R²（经度）** | **0.064** | 几乎没有 |
| P90 误差 | 10,684 km | 10% 的词被丢到地球另一边 |

**探针判定**：`signal_ok = True`，但**只是勉强通过** ——
我的判据是 `control < 0.6 × permuted = 3,273 km`，实际 3,103 km，**只留了 5% 余量**。

> 所以正确的表述是：**「地理信息在最后一层是线性可解码的，但强度很弱」**，
> 不能说「模型知道地理位置」。

**量级参照**：
- 3,103 km ≈ 北京↔乌鲁木齐（2,400 km）的 1.3 倍
- 意味着模型能大致分出「欧洲 vs 美洲 vs 亚洲」，但**分不清「巴黎 vs 罗马」（1,105 km）**

## 三、最有价值的发现：纬度 vs 经度严重不对称

```
R²(纬度) = 0.427   ← 南北位置，可解码
R²(经度) = 0.064   ← 东西位置，几乎不可解码
```

### 这个发现只有「分维度报告 R²」才看得见

课程原实验写的是：

```python
r2 = r2_score(y_test, y_pred)     # 对 2 维输出做 uniform_average
```

那会得到 `(0.427 + 0.064) / 2 ≈ 0.245` —— **一个既看不出纬度好、也看不出经度差的数字**。

> **这是本项目建设性改造的直接回报**：
> 把 R² 拆成两个维度之后，一个原本会被平均掉的**结构性发现**浮现出来了。

### 为什么经度这么差？两个原因，第二个是真缺陷

**原因 1（模型的）**：从误差明细看，预测的经度几乎全部被压到 **-37° ~ +24°** 这个窄区间，
而真实经度跨度是 -103° ~ +43°。

```
Jamaica   真 -77.3° → 预 16.2°      Georgia  真 +43.4° → 预 -36.6°
Panama    真 -80.8° → 预 -13.7°     Mexico   真 -102.6° → 预 -31.5°
Chile     真 -71.5° → 预 -27.6°     Congo    真 +23.9° → 预 -23.1°
```

**这是典型的「回归到均值」**：模型对经度几乎给不出有效信号，
Ridge 于是把输出收缩到训练集均值附近。

**原因 2（我代码的缺陷）：经度是循环量，线性回归处理它有偏。**

经度 179° 和 -179° 在地理上是相邻的（只差 2°），
但在目标空间里相差 358°。线性回归无法表达这种周期性。

```
线性编码（现状）：  λ = -179, ..., 0, ..., +179      ← 首尾不连续
正确编码：          (sin λ, cos λ)                    ← 在单位圆上连续
```

**这是一个真实的建模错误，应该修。** 修复后 `R²(经度)` 很可能大幅上升 ——
届时「经度学不好」到底是模型的问题还是编码的问题，才能分清楚。

> **重要**：在修复之前，**不要**把「经度不可解码」写成结论。
> 目前只能说「在我们的线性经纬度编码下，经度不可解码」。

## 四、一个更强的假设：模型是「欧洲中心」的

把 20 个歧义词按误差排序，出现了一个清晰的模式：

| 属于 | 词（误差升序） |
|---|---|
| **旧大陆（欧/亚/非）** | Naples 395、Niger 191、Athens 1,308、Washington 1,363、Guinea 1,415、York 2,569、Lebanon 3,403、Granada 3,578、Cordoba 4,029、Toledo 4,121、Valencia 4,386 |
| **新大陆（美洲）** | Colombia 4,913、Florence(误)→、**Chile 6,382、Santiago 6,687、Mexico 7,015、Panama 7,416、Jamaica 9,766** |

**所有美洲词的误差都在 6,000 km 以上；所有欧亚非词都在 5,000 km 以下。**（除了几个跨洲混淆的）

**这与「经度不可解码」是自洽的**：
- 高频地名（欧洲、北非、近东）的经度集中在 **-10° ~ +40°** 这个窄带里
- 模型只需要在这个窄带内区分就够用了
- 所以它的经度表征就被"压缩"在这个范围 —— 美洲（经度 -60° ~ -120°）被系统性拉回

**这是一个比"经度不可解码"更具体、更有解释力的假设**：

> **模型的地理表征可能是「以训练语料密度为权重」的，而不是「以地球几何为坐标」的。**
> 语料里密集的区域（欧美核心区）表征分辨率高，稀疏区域（南美、非洲腹地）被压缩。

**这个假设可以被检验**（见第六节下一步 3）：按大洲分层统计误差，
如果欧洲组显著优于美洲组，假设成立。

## 五、歧义效应：证据不足，且「偏向」判定大部分是噪声

### 5.1 整体：1.25 倍，不显著

| | 中位误差 | 标准差 |
|---|---|---|
| 对照组 | 3,103 km | 685 |
| 歧义组 | 3,869 km | 691 |

**差值 766 km，而两组的标准差都是 ~690 km。**
粗算 `766 / 688 ≈ 1.1σ` —— **远未达到显著水平**。

所以报告里写的「歧义无明显影响」是**正确且保守**的结论。

### 5.2 原来「6/20 偏向备选」这个数字是误导性的

> **✅ 已修复**：见第 5.4 节的更新结论。这一小节保留原始分析，用来记录问题是怎么被发现的。

原来的 `alt_preference_analysis` 只比较"预测点离哪个候选更近"，
**没有检查"最近的那个候选本身是不是就近"**。

看实际的 6 个「偏向备选」案例：

| 词 | 到主含义 | 到备选 | 差值 | 判断 |
|---|---|---|---|---|
| Santiago | 6,687 km | 6,675 km | **12 km** | ❌ **纯噪声** |
| Panama | 7,416 km | 7,276 km | 140 km | ❌ 两边都 7,000+ |
| Mexico | 7,015 km | 6,859 km | 156 km | ❌ 两边都 7,000 |
| Georgia | 7,469 km | 4,607 km | 2,862 km | ⚠️ 差值大，但 4,607 仍然很远 |
| **Valencia** | 4,386 km | **2,990 km** | 1,396 km | ✅ **较可信** |
| Colombia | 4,913 km | 3,942 km | 971 km | ⚠️ 略超门槛 |

> **这是一个方法论缺陷**：判定「偏向哪个含义」时，
> 必须要求**至少一个候选足够近**，否则这个比较没有意义。

### 5.3 一个正面证据：模型确实区分了 Niger / Nigeria

| 词 | 到主含义（尼日尔） | 到备选（尼日利亚） |
|---|---|---|
| `Niger` | **191 km** | 961 km |

**191 km 的误差** —— 模型把尼日尔放得非常准，而且**没有**被更常见的尼日利亚带偏。

**这是「模型对高频地名有精确表征」的直接证据**，也说明探针本身是有效的。

### 5.4 ✅ 修复后的更新结论

**已实现**：
1. `TargetEncoder("sincos")` —— 经度循环编码
2. `alt_preference_analysis(..., reliability_km=...)` —— 可靠性门槛

**门槛设计成自适应的**：`有效门槛 = max(配置下限, 模型自身中位误差)`

```
本次门槛 = max(2500, 3103) = 3,103 km
```

为什么不用固定 2,500 km：**它比模型自身误差（3,103 km）还严**，
会把模型定位正常的词也判成不可靠 —— 连 Valencia（2,990 km）都会被误排除。
判据的自然含义应该是："最近候选至少要和模型平时一样准，才谈得上'偏向'。"

**重算后的结果**：

| | 数值 |
|---|---|
| 判定可靠 | **8 / 20** |
| 可靠判定中偏**主含义** | **7 个** |
| 可靠判定中偏**备选含义** | **1 个**（Valencia） |
| 被排除（两边都太远） | 12 个 |

**可靠判定的明细**：

| 词 | 最近候选距离 | 偏向 |
|---|---|---|
| Niger | 191 km | 主 |
| Naples | 395 km | 主 |
| Athens | 1,308 km | 主 |
| Washington | 1,363 km | 主 |
| Guinea | 1,415 km | 主 |
| Alexandria | 2,410 km | 主 |
| York | 2,569 km | 主 |
| **Valencia** | **2,990 km** | **备选** |

**结论发生了实质变化**：

> 原来："6/20 偏向备选 → 表征被语料频率主导"
> **现在："8 个可靠判定中 7 个偏主含义，仅 Valencia 偏备选
> → 模型倾向于保留地理含义，歧义的影响没有原以为的那么大"**

**被排除的那 12 个里包含了原来最"抢眼"的 5 个**：
Georgia、Colombia、Santiago、Mexico、Panama —— 它们的最近候选都在 4,000 km 以上，
所谓"偏向"完全来自噪声。**如果不加这个门槛，就会得出一个错误的结论。**

## 六、下一步：按价值排序的动作

### ① ✅ 已实现：经度的循环编码

`--target-encoding sincos` 已可用。合成数据上的效果：

| 编码 | 全部点经度中位误差 | 跨日界线点（\|lon\|>150°） |
|---|---|---|
| `latlon` | 38.3° | **127.7°** |
| `sincos` | **0.2°** | **0.2°** |

**下一步就是用真实模型跑：**

```bash
python -m geoprobe run --repeats 5 --target-encoding sincos
```

如果 `R²(经度)` 明显上升 → 说明原来那个 0.06 是**编码的错**，不是模型的错。
如果仍然是 0.06 左右 → 才是"模型确实不编码经度"的可靠结论。

**为什么这一条优先级最高**：它决定「经度不可解码」是**模型的属性**还是**我的建模错误**。
不修这个，第四节的「欧洲中心」假设也无法确证。

### ② Layer sweep（找最佳层）

现在只测了第 23 层（最后一层）。但 probing 文献的常见结论是
**世界知识在中层最强**，最后一层反而被"下一个 token 预测"的目标挤压。

```bash
python -m geoprobe layer-sweep --repeats 3
```

**预期**：如果某个中间层（比如 12~18 层）明显更好，
现在这个 `signal_ok=True` 但勉强通过的结果，会变成明确的正面结论。

### ③ 按大洲分层分析（验证「欧洲中心」假设）

在词表里给每个词加大洲标签，然后分组统计误差。

**预期**：欧洲组 < 北美组 < 南美/非洲组。
如果成立，「表征被语料密度加权」就是一个能写进报告的核心结论。

## 七、这个结果能写进简历吗

**能，但必须这样表述**（诚实且具体）：

> 在 Qwen2.5-0.5B 的第 23 层上做线性探针，108 个无歧义地名的留出集
> **中位误差 3,103 km**，显著优于置换检验（5,455 km）与字符 n-gram 基线（5,268 km），
> 说明地理信息在该层**线性可解码但强度较弱**。
> **分维度报告发现强烈不对称：R²(纬度)=0.43，R²(经度)=0.06** ——
> 模型能区分南北，但几乎无法定位东西；且所有美洲地名的误差（6,000+ km）
> 都远高于欧亚非（<5,000 km），暗示表征可能按**训练语料密度**加权而非按地球几何。
> 歧义地名（Georgia / Turkey 等）误差放大 1.25 倍，但**未达统计显著**，故不下结论。

**为什么这样写比"我做了一个探针实验"强**：
- 有具体数字（可复现）
- 有**负面结果**（歧义不显著）—— 说明不硬凑结论
- 有**结构性发现**（纬度 vs 经度不对称）
- 有**方法论自觉**（指出经度编码是自己代码的缺陷，待修）

> **面试官最可能追问的一句**："经度为什么学不好？"
> 你的回答应该是：「两种可能 —— 模型的表征确实以语料密度加权，
> 或者我的线性经纬度编码对循环量有偏。
> 我已经识别出后者是真实缺陷，下一步会用 sin/cos 编码排除它。
> **在没有排除之前，我不会把'经度不可解码'当成结论。**」

**这个回答的价值**：它展示的是**区分"发现"与"方法缺陷"的能力**，
而不是"我跑出了一个结果"。

## 九、这次修复带来的方法论教训

三个修复合起来说明同一件事：**"结果不好"和"方法有错"很难区分，必须主动去区分。**

| 现象 | 天真的结论 | 追查后发现 |
|---|---|---|
| R²(经度) = 0.06 | "模型不编码经度" | 一半是**线性编码对循环量有偏** |
| 6/20 偏向备选含义 | "表征被语料频率主导" | 4 个是**两边都没定位准的噪声** |
| 歧义 1.25× | "歧义有影响" | 与噪声同量级，**证据不足** |

**这就是 probing 这类分析的核心难点**：
数字总是有，但要判断"这个数字反映的是模型，还是我的方法"。

面试时如果被问到"你怎么保证结论不是方法造成的"，
这三个例子就是最好的回答 —— 每一个都能说清"我怎么发现、怎么排除"。
